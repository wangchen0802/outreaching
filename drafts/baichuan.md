## 调研备注

**最近发布**
- **Baichuan-M4 和"百小医"**：2026-05-26 在清华发布，技术报告 2026-06 上 arXiv（v2 于 06-10 公布）。M4 不开源，只提供 API（搜索摘要）。多家媒体报道它在 HealthBench、HealthBench Hard、HealthBench Professional 三个榜单都排第一（Professional 55.1），裸模型事实性幻觉率 3.3%（搜索摘要）：https://finance.sina.com.cn/tech/2026-05-26/doc-inhzezks9075156.shtml 、https://arxiv.org/abs/2606.08982 。百小医是跑在微信里的 AI 家庭医生，负责记录全家人的用药和检查数据、提醒复诊。
  - 系统有三部分：Baichuan-Harness 运行时，让训练和部署用同一套接口、动作约束和患者记忆；用持续照护 RL 框架训练的核心推理模型；临床工具层，包括患者记忆、循证检索，以及文档、X 光、皮肤科的多模态能力。
  - SPAR++：不再给整段对话打一个总分，而是把奖励锚定到关键临床片段上，包括病史采集是否充分、风险是否及时识别、工具用得对不对。效率奖励只在医疗质量分过线后才生效。
  - 外层是"在线自进化"：线上 bad case、用户追问、医生纠正、低置信回答和工具异常，都会转成评测样本和训练数据。
  - 循证：证据库分六层，有 4,000 多万条生物医学记录。自建的 Baichuan-EBM 评测上，引用精度 90.0，GPT-5.5 是 54.7。
  - 发布会口径：医学指南被拆成 1,000 多条原子化临床路径（SKILL），覆盖 200 多种疾病，每条由资深临床专家定义和校验（两次搜索的摘要里都有，未读原文）：https://news.qq.com/rain/a/20260526A09SZI00
  - 以上技术细节来自 arXiv 页面的搜索摘要和 GitHub 上的第三方论文解读（https://github.com/luohongk/Embodied-AI-Daily/blob/main/summaries/2606.08982.md ），不是报告原文。
- **Baichuan-M3**：2026-01 开源，235B，基座是 Qwen3，训练框架用 verl；技术报告 2026-02 发布。README 写明了以下几点（已读原文）：https://github.com/baichuan-inc/Baichuan-M3-235B
  - SPAR 把临床流程拆成病史采集、鉴别诊断、检验检查、精确诊断四个奖励阶段，配合过程级奖励。
  - Fact-Aware RL：在 RL 循环里接入在线幻觉检测，依据是权威医学证据。
  - 训练分三阶段：领域专项 RL → 离线蒸馏 → MOPD 在线优化。HealthBench-Hard 44.4。
  - SCAN-bench 是自建的动态问诊评测，模拟从接诊到确诊的全过程。据报道有 150 多位一线医生按 OSCE 思路参与构建（搜索摘要）。
- **M3 Plus**（2026-01 下旬）：做了证据锚定，幻觉率 2.6%；通过"海纳百川"计划向合作方免费开放 API（搜索摘要）。官方 MCP Server 仓库也写了 2.6% 和"六源循证"（已读原文）：https://github.com/baichuan-inc/baichuan-mcp-servers
- **Baichuan-M2**（2025-08，超出 9 个月，只作背景）：README 写明用了"大型验证器系统"，包括基于真实病例的患者模拟器、8 个维度的验证，以及实时生成评分标准（已读原文）：https://github.com/baichuan-inc/Baichuan-M2-32B

**切入点**
- 片段级临床评分标准：SPAR++ 要按病史采集、风险识别、工具使用逐段打分。M4 从问诊扩展到随访、慢病、用药、检查解读和家庭成员管理，这些新场景都需要医生来写和审 rubric。
- 循证标注：把医学结论对应到指南或论文的具体段落，为 Fact-Aware RL 和证据锚定做校验集和留出评测集。
- 标准化病人剧本和 OSCE 式动态评测：给患者模拟器和 SCAN-bench 类评测补病例，重点是百小医的家庭场景（儿科、老年、慢病）。
- 多模态：X 光报告、皮肤科、医疗文档 OCR 的专家标注和评测。
- SimReal 现有的环境里没有医疗方向，能卖的是医生专家数据（rubric、偏好数据、评测集），不是环境。

**风险**
- 自有医生资源很强：有 150 多位医生参与的自建评测、上百位三甲专家做标注，还和清华合作。M4 的线上自进化闭环也会持续从真实用户和医生纠正里产出数据。外部数据的空间主要在新场景和留出评测。
- 医疗数据合规：健康数据属于敏感个人信息，病例和对话数据基本不可能出境。专家需要有中国执业医师资质、熟悉国内指南。发送前请确认专家池里国内执业医生和药师的实际人数，不要夸大。
