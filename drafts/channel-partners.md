# 渠道伙伴外联模板（国内数据供应商）

对象：`intel/china-targets.html` 里"渠道伙伴"一栏。目的是**分包或联合交付**：对方有大模型客户，我们补高端专家供给和 RL 环境/验证器。

方括号里的内容由你填或决定；其余文字尽量不改。

## 发送前请确认

1. **Surge AI 和 AfterQuery 的合作要真实、可以公开说。**
   - `drafts/surge-ai.md` 里 Surge AI 还是我们的外联对象。如果双方只是在谈，没有签约或实际交付，请用下面的"弱版"写法。
   - 国内同行很可能私下打听核实。一旦被发现说过头，对方就不会再信任我们。
   - 如果签了保密协议，要先确认能不能点名。
2. **专家数量说的是"可触达 20 万+ 专业人士"，外加"7,000+ 已报名候补名单"。**
   - 不要写成"7,000 名签约专家"或"20 万专家库"。对方做数据交付，第一个问题就会是"现在能开多少人"。
3. **融资只说"在和几家一线机构沟通"，不点名机构、不说估值。**
   - README 原来的约定是"不提融资"。这次按你的要求写进去了，但只放一句。
   - 对方也可能是竞争对手，说多了会暴露我们的节奏。
4. **合规。** 渠道伙伴的最终客户多是国内大模型公司，有些可能在美国出口管制清单上。签分包前，要确认海外专家参与交付和数据跨境是否受限。
