# 外联模板（第 3 版）

三类对象：渠道伙伴（第一步）、投资人、客户。发件邮箱 business@simreal.co。

每封只改这些方括号：[Company] / [公司名]、[Name] / [称呼]、[Hook] / [合作句] / [投资句]。
[Hook] / [合作句] / [投资句] 是一句：对方最近做的一件事（核实过），加上我们为什么找他们。
以下保持原样，由发件人填：[Your name]、[姓名]、微信/电话：[ ]、[介绍人]。

背书里的每个数字都来自 BP（Delta1 仓库）或你在对话里给的事实：
- 团队：剑桥、LSE、杜克；Jane Street、Citadel、D. E. Shaw、Millennium、Optiver 从业经历；四人都放弃了 return offer。
- 产品：成立 14 天、零外部融资做出 7 款产品；Xitadel 让 Qwen3.8-27B 在从未见过的真实行情上交易表现提升 12%，多次独立运行均复现；公开版前沿模型最高 77.3 分，人类参考线 80 分。
- 质量：谜题基准 400 次作弊攻击 0 次成功；财务结账环境评分漏洞 6 → 0。
- 专家：7,000+ 已报名；通过 21 所合作高校可触达 20 万+ 专业人士（不写"20 万已验证专家"）。
- 合作与融资（你提供）：已和 Surge AI、AfterQuery 合作；正在融资，和一线机构接触。投资人邮件写 2,000 万美元种子轮（BP）。
- 进展（BP）：两家前沿实验室在洽谈；首周 GitHub 500+ 星标（不放链接）。这两条还没确认，投资人短版邮件（2026-10）不写。
- 投资人邮件用短版（英文约 120 词）：投资人每周收几百封 AI 写的长邮件，拿到回复的冷邮件大多不到 100 词。
