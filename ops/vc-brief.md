# 调研说明：投资 RL 环境 / 后训练数据赛道的 VC

## 目的
SimReal（simreal.co）做大模型后训练用的 RL 环境、验证器和专家数据，团队来自 Citadel、Millennium、Jane Street，处在种子轮。我们要一份**投资人名单**：哪些机构和个人已经投了这个赛道（RL 环境、人类数据/专家网络、评测、合成数据、后训练基础设施），谁是负责的合伙人，他们公开说过什么，以及对我们的匹配度。

今天是 2026-09-26。你的训练知识已经过时，一切以搜索结果为准。

## 起点
`intel/vc-seed.csv` 是之前调研顺带收集的 133 条投资关系（投资方 → 被投公司），先读它。在此基础上补全和扩充。

## 每家机构要查
1. 本赛道已投公司：公司、轮次、金额、日期、是否领投，每条附来源链接。
2. 负责这些交易的合伙人：姓名、职位、来源链接（融资稿、机构官网团队页、合伙人自己的博客或推文）。查不到写"未找到"，不要猜。
3. 公开观点：合伙人或机构关于 RL 环境、后训练数据、AI 基础设施的公开文章、播客、推文，摘一句原话并附链接。
4. 阶段和金额：通常投哪一轮、单笔多少（有公开信息才写）。
5. 冲突：是否投了和 SimReal 直接竞争的公司（例如 Mercor、Surge、AfterQuery、Fleet、Mechanize 等做 RL 环境或专家数据的公司）。投过竞品不一定排除，但要标出来。
6. 对 SimReal 的匹配度（高/中/低）和一句理由：阶段是否对得上、是否有这个赛道的认知、是否投过量化或金融背景的年轻团队、中美背景是否合适。

也要覆盖：
- 实验室和大厂的战略投资（NVIDIA、Google/GV、Datadog 等）
- 活跃的天使：前沿实验室研究员、数据公司创始人
- 加速器：YC、AI Grant 等

## 只用公开信息
- 只用公开职业信息和公开发布的内容。不冒充身份，不联系任何人，不登录任何平台，不在 LinkedIn、脉脉、微信上做任何操作。LinkedIn 链接只能作为搜索摘要里看到的旁证。
- 不猜测。每条都要有来源链接；只在搜索摘要里看到的，写明"搜索摘要"。

## 环境限制
- WebSearch 可用，本会话额度 200 次，到 190 次停。
- 大多数网站不能直接打开，只能看搜索结果；`curl -sSL https://raw.githubusercontent.com/...` 可以读 GitHub 上的文件。

## 输出（写在仓库里，文件名前缀用你的分段名）
1. `intel/<分段名>-funds.csv`（UTF-8，带表头），一行一家机构或一位天使，列：
   `投资方,类型,地区,本赛道已投,领投过的,常投阶段和金额,对接合伙人,合伙人来源链接,公开观点原话,观点链接,投过的直接竞品,匹配度,匹配理由,置信度`
   - 类型：VC / 战略投资 / 天使 / 加速器
   - 多个值用"；"分隔
   - 置信度：高 = 融资稿、机构官网、本人发布；中 = 权威媒体；低 = 间接或只有搜索摘要
2. `intel/<分段名>-deals.csv`，一行一笔交易，列：
   `被投公司,赛道,轮次,金额,日期,领投方,跟投方,来源链接,置信度`
3. `intel/<分段名>-vc-notes.md`：最值得先接触的 15 家（排序加一句理由）、这个赛道最近 12 个月的融资节奏和估值水平、对 SimReal 融资叙事的建议（≤400 字，中文）。

写完检查 CSV 列数一致，然后只提交 `intel/` 下你自己的三个文件，推送到本会话的分支。不要修改其他文件。
