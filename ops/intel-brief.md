# 调研说明：RL 环境 / 数据公司公开声明的客户与合作方

## 目的
SimReal（simreal.co）卖后训练用的 RL 环境、验证器和专家数据。我们想知道这个市场上**谁在买、买什么、同时用几家供应商**。方法：把 RL 环境、人类数据、专家网络、标注、评测、合成数据这类公司**自己公开声称**的客户、合作方、共建方收集起来，做成一张"供应商 → 客户"的关系表，再由协调会话做反向索引。

今天是 2026-09-25。你的训练知识已经过时，一切以搜索结果为准。

## 只用公开信息
- 只收集已经公开的声明：官网客户墙和案例（通过搜索结果或转述看到）、新闻稿、融资稿、媒体报道、上市公司财报和招股书、论文和技术报告的致谢与作者单位、共建的基准、招聘描述、公开访谈和演讲、公开诉讼文件。
- 不冒充任何身份，不联系任何人，不注册、不登录任何平台，不在 LinkedIn、脉脉、微信等平台上做任何操作。LinkedIn/脉脉链接只能作为搜索摘要里看到的旁证。
- 不猜测。每一行关系都要有来源链接；只在搜索摘要里看到的，写明"搜索摘要"。

## 环境限制
- WebSearch 可用。本会话有 200 次搜索额度；到 190 次就停，用已有信息收尾。
- WebFetch / curl 对大多数网站被网络策略拦截（公司官网、招聘网站、arXiv、新闻站、港交所等）。
- 能用的：`curl -sSL https://raw.githubusercontent.com/<owner>/<repo>/<branch>/<path>` 读 GitHub 上的文件（模型 README、技术报告 PDF、基准仓库、github.io 主页的源码）。PDF：`python3 -m venv /tmp/v && /tmp/v/bin/pip install -q pymupdf`，然后用 `import pymupdf` 读。
- 技术报告和模型卡的致谢部分很有价值（例如 "we thank Surge AI / Scale AI for data annotation"），GitHub 上的 PDF 和 README 可以直接读原文。

## 找什么线索（按效率排序）
1. 供应商融资稿和媒体报道里的 "customers include …" / "works with …"。
2. 上市公司财报、招股书里点名或描述的大客户（Innodata、Appen、TELUS Digital、海天瑞声等；招股书常有前五大客户名称）。
3. 模型技术报告、论文、系统卡的致谢和作者单位（供应商帮哪家做了数据或评测）。
4. 共建的基准、评测、数据集（例如某供应商和某实验室联合发布的 benchmark）。
5. 招聘描述里的客户暗示（"work directly with leading AI labs such as …"）。
6. 公开诉讼、新闻里的客户变动（例如某实验室暂停和某供应商合作）。
7. 官网客户墙：本环境打不开官网，只有在搜索摘要、媒体转述或第三方页面里出现时才记录，关系类型写"官网客户墙（转述）"。

## 输出（写在仓库里）
1. `intel/<你的分段名>-vendors.csv`（UTF-8，带表头），列：
   `供应商,类型,规模,地区,官网,简介,主要领域,收录声明数`
   - 类型：人类数据/专家网络、RL 环境、评测、标注平台、合成数据、综合（多选用"/"）
   - 规模：大（年收入或估值很高 / 上市 / 员工很多）、中、小（种子到 A 轮、团队很小）。写一句依据放在简介里。
2. `intel/<你的分段名>-claims.csv`（UTF-8，带表头），一行一条关系，列：
   `供应商,客户或合作方,客户类型,关系类型,工作内容或领域,原文证据,来源链接,来源日期,来源类型,置信度`
   - 客户类型：frontier lab / 国内大模型公司 / 科技大厂 / AI 应用公司 / 垂直 AI / 金融机构 / 企业 / 政府 / 高校研究机构 / 其他
   - 关系类型：客户 / 合作 / 共建基准 / 论文致谢 / 财报披露 / 招聘暗示 / 官网客户墙（转述）/ 客户变动（停止合作等）/ 投资方
   - 原文证据：一句短引文（≤40 词或 ≤60 字）
   - 置信度：高 = 供应商或客户官方发布、财报、论文原文致谢；中 = 权威媒体报道；低 = 间接、二手转述、只有搜索摘要、或时间较早（2024 年前）
   - 同一对"供应商–客户"有多个来源时，各写一行。
3. `intel/<你的分段名>-notes.md`：你的分段覆盖了哪些供应商、哪些没查到、最有价值的发现（谁是最大买家、哪些领域需求最集中、有什么我们没想到的买家），以及你对 SimReal 的建议（≤400 字，中文）。

写完后运行下面的检查，确保 CSV 列数一致，然后只提交 `intel/` 下你自己的三个文件，推送到本会话的分支：
`python3 -c "import csv,sys; [print(f, set(len(r) for r in csv.reader(open(f,encoding='utf-8')))) for f in sys.argv[1:]]" intel/<分段名>-*.csv`

不要修改仓库里的其他文件。
